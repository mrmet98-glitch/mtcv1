# Airline and transfer-partner logos

Upload logo files to this folder using these exact lowercase base names:

- `united`
- `delta`
- `american`
- `chase`
- `amex`

Each logo may use **one** of these extensions: `.webp`, `.png`, `.jpg`, or `.jpeg`.
For example: `united.png` or `amex.webp`.

The site tries those extensions automatically in that order. Transparent PNG or WebP files work best. Images are fitted inside fixed containers with `object-fit: contain`, so they will not stretch or overflow. If a file is absent, the interface keeps its letter/text fallback instead of displaying a broken image.
